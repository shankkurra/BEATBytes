BEATBytes is the desk's daily one-paragraph note to electronic trading clients, sent at 10:30 via Bloomberg chat. The link in the ABOUT section and below takes you to the console with the full curated library, tells you exactly what to send today, and keeps a shared send log so the whole team sees the same rotation.

Direct link to the console: https://shankkurra.github.io/BEATBytes/BEATBytes.html
